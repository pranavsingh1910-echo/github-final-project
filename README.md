# Simple Interest Calculator

## Description
A simple interest calculator that calculates simple interest and total amount using principal, rate, and time.

## Formula
Simple Interest = (P × R × T) / 100

Where:
- P = Principal Amount
- R = Rate of Interest
- T = Time in years

## Example
Principal = ₹10,000  
Rate = 5%  
Time = 2 years  

Simple Interest = ₹1,000  
Total Amount = ₹11,000

## Features
- Easy to use
- Calculates simple interest
- Calculates total amount
- Simple and user-friendly
